# Nixring — Naming

## Chosen: **Nixring**

*"nix"* (to reject/cancel) + *"ring"* (an incoming call) → reads instantly as **"kill the call."**
Coined, 7 chars, ownable, call-forward for ASO.

- **App Store title:** `Nixring: Spam Call Blocker` (26 chars ≤ 30) — calls lead the title (highest-volume ASO term), texts move to the subtitle.
- **Subtitle:** `Block spam calls & junk texts` (29 chars ≤ 30) — covers both calls and texts.
- **Bundle ID:** `com.levinschwab.nixring` (+`.calldir`, +`.smsfilter`)

### Availability (verified 2026-07-19)
- iTunes Search API (US): resultCount 1 → only *"Nix Toolkit"* (Nix Sensor Ltd.), **no exact-name match**.
- iTunes Search API (DE): resultCount 0.
- Web/trademark search: no conflicting app, product, or mark.
- Cleanly avoids the likely-taken generics (CallShield, SpamShield, RoboKiller, Hiya, Truecaller).
